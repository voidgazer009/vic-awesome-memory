# 六大流派详解

## ① 事实抽取（Mem0 / LangMem / Memobase / Supermemory）
流程：对话 → LLM 抽取原子事实 → 与已有事实比对（ADD / UPDATE / DELETE / NOOP）→ 存向量库 → 检索时混合语义 + BM25 + 实体。
- ✅ 接入一行代码；token 成本低（Mem0 论文：约 1.8k vs 全量 26k token）
- ❌ 抽取是有损压缩：丢上下文、因果、语气；抽错一次就长期污染
- 💡 借鉴：写入时的"与旧记忆比对再决定增删改"

## ② 时序知识图谱（Graphiti/Zep / Cognee / GraphRAG）
实体为节点、关系为边；Graphiti 每条边带 `valid_at / invalid_at`（事件时间）与 `created_at / expired_at`（系统时间）。
- ✅ "去年在 A 公司，现在在 B 公司"可以同时正确回答；可审计
- ❌ 每次写入多次 LLM 调用，延迟与成本高
- 💡 借鉴：**矛盾时失效旧事实而不是删除**

## ③ 记忆操作系统（Letta/MemGPT / MemOS / MemoryOS）
上下文 = RAM，外部存储 = 磁盘；agent 通过工具自己换入换出、编辑核心块。
- ✅ 适合长期自主 agent，记忆随任务自我维护
- ❌ 依赖模型"记得去调用记忆工具"，弱模型表现差
- 💡 借鉴：分层 + 容量上限 + 晋升/淘汰策略

## ④ 文件优先（ai-memory / Basic Memory / claude-mem / OpenViking / GBrain）
Markdown 文件（常配 Git）是唯一真相，向量/全文索引是可重建的派生物。
- ✅ 人可读可改、可 diff、可迁移、无厂商锁定、天然多 agent 共享
- ❌ 大规模检索需另建索引；并发写需处理
- 💡 借鉴：**可解释 + 可导出** 应是任何记忆系统的底线

## ⑤ 类脑 / 认知科学（HippoRAG / A-MEM / LightMem / MIRIX / Generative Agents）
直接移植认知机制：海马体索引、扩散激活、遗忘曲线、睡眠巩固、卡片盒链接。
- ✅ 多跳关联、自然遗忘、记忆自我进化
- ❌ 多为研究代码，生产化不足
- 💡 借鉴：这是"无限接近人脑"的唯一路线，但要工程化

## ⑥ 参数化 / 激活记忆（MemOS MemCube、KV-cache 复用、LoRA 记忆）
把高频记忆写进 KV-cache 或微调权重。
- ✅ 推理快，像"内化"的知识
- ❌ 难解释、难精确删除（隐私合规难）、需要模型访问权限
- 💡 借鉴：只适合稳定、高频、非隐私的知识

## 结论：没有一个流派是完整的大脑
人脑同时拥有：过滤（①的写入判断）、时间线（②）、容量管理（③）、可追溯原件（④）、关联与遗忘（⑤）、内化技能（⑥）。
**vic-memory 的设计目标就是把 ①–⑤ 组合成一个模型无关的整体。**
