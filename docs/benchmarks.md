# 评测与"水分"

## 主流基准
- **LoCoMo**（Snap, 2024）：10 段超长多会话对话 + QA，问题类型：单跳、多跳、时间、开放域、对抗。
- **LongMemEval**（ICLR 2025）：500 题，五种能力：信息抽取、跨会话推理、时间推理、知识更新、拒答。
- **BEAM**：100K 到 10M token 规模。

## 为什么厂商分数不可横比
1. 回答模型不同（gpt-4o-mini vs gpt-5.x 差距巨大）
2. 裁判模型与评分提示不同
3. 子集/变体不同，有的未公开题目数
4. 托管版与开源版不是同一套算法（Mem0 自述开源用户只能期待"方向相似"的提升）

## 一个必须知道的事实
Mem0 2025 论文（gpt-4o-mini 作答）：Mem0 66.9、Mem0-graph 68.4、Zep 66.0、LangMem 58.1、OpenAI memory 52.9、A-Mem 48.4，而**全量上下文 72.9 高于所有记忆系统**。
记忆系统的价值在于：**用少一个数量级的 token、低一个数量级的延迟，逼近甚至在超长场景超越全量上下文**——尤其当历史超过上下文窗口时，全量上下文根本不可行。

## 我们的评测原则（vic-memory 遵循）
- 公布回答模型、裁判模型、题目数、运行次数
- 同时报告：准确率、检索召回、每次查询 token、p50 延迟
- 必须包含"知识更新"和"拒答"两类——这才是记忆与检索的区别
